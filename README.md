# 🧠 Handwritten Text Recognition (CRNN)
A deep learning web app that recognizes handwritten text using a CRNN trained on the IAM Handwriting dataset.

## 🌐 Live Demo
👉 https://handwritten-text-recognition-project-lb2crqdyjphfksgpj8mswc.streamlit.app/

## 🧩 Features
- Trained on IAM Dataset (~38k samples)
- Real-time handwriting recognition
- Simple Streamlit web interface
- Auto-downloads model from Google Drive

## 🚀 Run Locally
```bash
git clone https://github.com/Solankys123/handwritten-text-recognition-project.git
cd handwritten-text-recognition
pip install -r requirements.txt
streamlit run app.py
